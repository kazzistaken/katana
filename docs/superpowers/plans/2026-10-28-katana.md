# Katana Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A new standalone Electron app. Projects are trusted folders; in each project's chats, a hidden Manager splits requests across up to 4 hidden Claude Code workers. The app shows only the live tool calls and a ✓/✗ summary, and never shows a terminal.

**Architecture:**
- **Main process:** runs one `claude -p` process per turn (both Manager and workers), resumed by session ID, and streams parsed events to the renderer as `run:event`. It refuses worker turns outside trusted folders.
- **Renderer:** the Manager loop is copied from XodeCode (`manager.js`, dependency-injected). It gets two adapters, `managerApi` (the Manager's turns) and `createWorkerPool` (the workers), plus plain DOM views for the sidebar, chat and settings.

**Tech Stack:** Electron 38, plain ES modules (no bundler), Node `assert` test scripts, and a look-test harness that saves screenshots.

- **Models:** default Manager is `claude-sonnet-5-5` at effort `low`, default worker is `claude-sonnet-5-5` at effort `medium`. The choices are Opus `claude-opus-5-5`, Sonnet `claude-sonnet-5-5` and Haiku `claude-haiku-5-5`.
- **Limits:** at most 4 workers per chat; 200 saved messages per chat; titles trimmed to 40 characters.
- **Exact copy:**

  - Trust dialog body: "Claude workers can read, edit and run commands in <path> without asking."
  - Trust dialog buttons: "Trust folder" and "Cancel".

  - No projects: a button reading "Add a project folder".
  - Missing folder: "Folder not found: <path>".
  - No Claude: "Claude Code not found. Install it and sign in, then restart."

## Review Focus

1. **Trust enforcement lives in main, not just the UI.** A worker `run:start` whose `cwd` isn't a saved project path must be refused. Test in Task 2: `runGuard refuses an untrusted cwd`.
2. **A worker session that can't be resumed** (deleted or expired) must clear its saved `sessionId` and retry once fresh, not loop. Test in Task 4: `resume failure retries once without a session`.
3. **Stop must cancel the hidden workers too.** Nothing may keep running unseen. Test in Task 4 (`cancelAll`) and in Task 7's wiring step.
4. **Deleting a chat or project mid-run** cancels its runs first. Test in Task 6: `deleting a chat cancels its runs`.
5. **A Manager turn that ends without a result** must reach `manager.js` as `dead`, so the request fails instead of hanging. Test in Task 5: `exit without result becomes dead`.

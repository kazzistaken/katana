XodeCode V2: logo concepts

Six directions, all on the app's own tokens: panel #111617 tile with a #3b4044 hairline, glyphs in #e6e9eb, and Katana's crimson #a3153a as the only accent. Mint is kept for the open mic, so no concept uses it. Each concept has a 512 master and a 16px version drawn separately on the 16-pixel grid.

Being replacedassets/xodecode.ico: a navy tile with a pixel X. The navy isn't in the palette, and BrowserWindow sets no icon, so the taskbar shows Electron's default.

01

Blade X_

monogram · katana · caret recommended

A Geist-Mono-weight X whose rising stroke is a katana: hilt, guard and an angled point. A crimson block cursor sits after it, so the mark reads as X_. The 16px version keeps a plain X and the red cursor.

Prompt Blade

terminal caret

The >_ prompt, with the chevron drawn as a single blade tapering to a point. The underscore is Katana's crimson caret, the same one used in the prompt bar. It holds up best of the six at very small sizes.

dithered dots
